# Техническое задание
## на программу «Поиск чисел Армстронга»

### 1. Основание для разработки

Программа разрабатывается в рамках учебной практики по профессиональному модулю ПМ.06 «Сопровождение информационных систем» (вариант 13). Задание выдано руководителем практики Шашковой В.Д.

### 2. Назначение разработки

Программа предназначена для поиска всех чисел Армстронга в диапазоне от 1 до числа N, которое указывает пользователь. Число Армстронга — число, равное сумме своих цифр, возведённых в степень, равную количеству цифр (например, 153 = 1³ + 5³ + 3³). Результаты поиска сохраняются в реестре найденных чисел.

### 3. Требования к программе

Программа работает в консоли и написана на Python 3, сторонние библиотеки не используются. Ввод верхней границы N и вывод найденных чисел выполняются через консоль, а также через файл: N читается из файла input.txt, результат записывается в файл output.txt. Каждый выполненный поиск добавляется в реестр найденных чисел (файл registry.txt).

Если пользователь ввёл не целое число или число меньше 1, программа должна вывести сообщение об ошибке и попросить ввести число заново.

### 4. Резервное копирование и восстановление

Программа должна создавать резервные копии реестра в папке backup (в имени копии указываются дата и время) и восстанавливать реестр из последней копии. Восстановление нужно, если файл реестра повреждён или удалён.

### 5. Порядок контроля и приёмки

Проверка выполняется тестами (файл tests.py) и тест-кейсами, приведёнными в отчёте по учебной практике. Программа считается принятой, если все тесты проходят и все пункты меню работают правильно.

### 6. Требования к документации
