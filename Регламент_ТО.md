# Регламент технического обслуживания

1. Программа не требует установки: достаточно, чтобы на компьютере был Python 3, а файлы проекта (main.py, backup.py, input.txt) лежали в одной папке.
2. Запуск программы выполняется командой `python main.py`, запуск тестов — командой `python tests.py`.
3. После каждого изменения кода нужно запускать тесты и убеждаться, что все они проходят.
4. После важных поисков следует делать резервную копию реестра (пункт 4 меню). Копии хранятся в папке backup.
5. Если файл registry.txt повреждён или случайно удалён, реестр восстанавливается из последней копии (пункт 5 меню).
6. Папку backup удалять нельзя. Старые копии при необходимости можно перенести на другой носитель (флешку, внешний диск).
7. Техническое обслуживание и исправления в коде выполняет автор проекта: Арюткин М.С., группа ИСП-31.
