# Техническое задание на программу «Поиск чисел Армстронга»

Настоящее техническое задание составлено по конспекту лекции 5
«Технология разработки программного обеспечения» (составитель В. Д.
Шашкова): разделы 1–5 повторяют последовательность C-требований
(требований заказчика), раздел 6 содержит обзор программного средства,
раздел 7 — требования разработчика.

## 1. Цель

Целью разработки является создание программы для учебной практики по
профессиональному модулю ПМ.06 «Сопровождение информационных систем»
(вариант 13). Программа должна находить все числа Армстронга в диапазоне
от 1 до числа N, которое указывает пользователь.

## 2. Область применения

Программа предназначена для использования в учебном процессе: на
практических занятиях, при демонстрации на защите практики и как простой
пример работы с числами и файлами на языке Python. Применение программы
в производственных условиях не предполагается.

## 3. Определения, термины, сокращения

Число Армстронга — число, которое равно сумме своих цифр, возведённых в
степень, равную количеству цифр. Например: 153 = 1³ + 5³ + 3³ = 1 + 125 + 27.

N — верхняя граница диапазона поиска, натуральное число, вводимое
пользователем.

Реестр — текстовый файл registry.txt, в который программа дописывает
результат каждого выполненного поиска.

Резервная копия — копия файла реестра в папке backup, которую программа
создаёт для последующего восстановления данных.

## 5. Краткое описание

Программа работает в консоли и показывает меню из шести пунктов: поиск
чисел с вводом N с клавиатуры, поиск с вводом N из файла input.txt и
выводом в output.txt, просмотр реестра найденных чисел, резервное
копирование реестра, восстановление реестра из копии и выход. Результат
каждого поиска сохраняется в реестре. Для реестра предусмотрены резервное
копирование и восстановление из последней копии.

## 6. Обзор программного средства

### 6.1. Системный интерфейс

Программа работает под управлением операционных систем Windows, Linux
или macOS и не требует прав администратора. Обращений к системным
службам нет: все данные хранятся в текстовых файлах рядом с программой.

### 6.2. Пользовательский интерфейс

Текстовый интерфейс в окне консоли: программа печатает меню, пользователь
вводит номер пункта и число N. Все сообщения выводятся на русском языке.

### 6.3. Аппаратный интерфейс

Используются стандартные устройства ввода-вывода: клавиатура и монитор.
Специальные требования к оборудованию не предъявляются.

### 6.4. Программный интерфейс

Внешние программы и библиотеки не вызываются. Используется только
стандартная библиотека Python 3 (модули os, shutil, datetime).

### 6.5. Коммуникационный интерфейс

Не используется: программа полностью работает на локальном компьютере,
сетевое подключение не требуется.

### 6.6. Ограничения по памяти

Для работы программы достаточно до 100 МБ оперативной памяти. Реестр и
резервные копии — небольшие текстовые файлы, занимают на диске несколько
килобайт.

### 6.7. Операции

Запуск программы выполняется командой `python main.py`, проверка тестов —
командой `python tests.py`. Все остальные операции выбираются в меню
программы.

### 6.8. Требования к адаптации рабочих мест

Не предъявляются: программа хранит все файлы в своей папке и работает из
любого каталога, в который она скопирована.

### 6.9. Функциональное описание

Программа должна:

- находить все числа Армстронга в диапазоне от 1 до заданного значения N
  включительно;
- принимать границу N с консоли или из файла input.txt;
- выводить результаты на экран или в файл output.txt по одному числу в
  строке;
- при некорректном вводе (текст вместо числа, число меньше 1,
  отсутствующий файл) выводить сообщение об ошибке и не завершаться
  аварийно;
- вести реестр найденных чисел registry.txt: дата и время, диапазон,
  найденные числа;
- создавать резервные копии реестра в папке backup и восстанавливать
  реестр из последней копии.

### 6.10. Характеристики пользователя

Пользователь должен уметь запускать программы из командной строки.
Специальные знания в программировании не требуются: все действия
выполняются через меню.

### 6.11. Ограничения

Срок разработки — период учебной практики с 05.10.2026 по 17.10.2026.
Язык разработки — Python 3, сторонние библиотеки не используются. Проект
выполняется одним разработчиком.

### 6.12. Допущения и зависимости

Поиск выполняется простым перебором всех чисел от 1 до N, поэтому при
очень больших значениях N поиск может идти долго. Работа программы
зависит от наличия установленного Python 3.

### 6.13. Распределение требований

Требования к поиску, вводу-выводу, реестру и проверке ввода реализуются
в файле main.py, требования к резервному копированию — в файле
backup.py, проверка выполнения требований — в файле tests.py.
Документация программы оформлена в файлах README.md, ТЗ.md и
Регламент_ТО.md.

## 7. Требования разработчика

Требования разработчика служат непосредственной базой для этапов
проектирования, реализации и тестирования программы. Они опираются на
C-требования из разделов 5 и 6 и на документы из раздела 4. По принципам
из конспекта лекции 5 каждое требование уникально идентифицировано
(ФТ-1–ФТ-6, НТ-1–НТ-4), требования структурированы по функциям программы
(по иерархии функций) и имеют ссылки к более ранней документации.

### 7.1. Функциональные требования

Функциональные требования перечислены в таблице 1. Проверка выполнения
каждого требования выполняется тестами из файла tests.py и
тест-кейсами, описанными в отчёте по практике.

Таблица 1 — Функциональные требования

| ID   | Требование |
|------|------------|
| ФТ-1 | Найти все числа Армстронга в диапазоне от 1 до заданного пользователем значения N включительно |
| ФТ-2 | Ввод границы N: запрос с консоли или чтение числа из файла input.txt |
| ФТ-3 | Вывод результатов: на экран либо в файл output.txt по одному числу в строке |
| ФТ-4 | Некорректный ввод (текст вместо числа, число меньше 1, отсутствующий файл) не вызывает аварийного завершения: программа выводит сообщение об ошибке |
| ФТ-5 | Ведение реестра найденных чисел registry.txt: дата и время, диапазон, найденные числа |
| ФТ-6 | Резервное копирование реестра в папку backup и восстановление из последней копии |

### 7.2. Нефункциональные требования

- НТ-1. Язык разработки — Python 3; используются только модули
  стандартной библиотеки (os, shutil, datetime), сторонние пакеты не
  устанавливаются (см. 6.4, 6.11).
- НТ-2. Программа состоит из простых функций без классов; оформление
  кода — по рекомендациям PEP 8: отступы в четыре пробела, имена в стиле
  snake_case.
- НТ-3. Все сообщения программы — на русском языке (см. 6.2);
  документация выполняется на русском и английском языках (README.md).
- НТ-4. Программа не требует прав администратора, хранит все данные в
  своей папке и работает из любого каталога (см. 6.1, 6.8).
