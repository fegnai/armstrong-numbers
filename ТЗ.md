# Техническое задание
## на программу «Поиск чисел Армстронга»

Настоящее техническое задание составлено по последовательности C-требований
(требований заказчика) из конспекта лекции 5 «Технология разработки
программного обеспечения» (составитель В. Д. Шашкова).

### 1. Цель

Целью разработки является создание программы для учебной практики по
профессиональному модулю ПМ.06 «Сопровождение информационных систем»
(вариант 13). Программа должна находить все числа Армстронга в диапазоне
от 1 до числа N, которое указывает пользователь.

### 2. Область применения

Программа предназначена для использования в учебном процессе: на
практических занятиях, при демонстрации на защите практики и как простой
пример работы с числами и файлами на языке Python. Применение программы
в производственных условиях не предполагается.

### 3. Определения, термины, сокращения

Число Армстронга — число, которое равно сумме своих цифр, возведённых в
степень, равную количеству цифр. Например: 153 = 1³ + 5³ + 3³ = 1 + 125 + 27.

N — верхняя граница диапазона поиска, натуральное число, вводимое
пользователем.

Реестр — текстовый файл registry.txt, в который программа дописывает
результат каждого выполненного поиска.

Резервная копия — копия файла реестра в папке backup, которую программа
создаёт для последующего восстановления данных.

### 5. Краткое описание

Программа работает в консоли и показывает меню из шести пунктов: поиск
чисел с вводом N с клавиатуры, поиск с вводом N из файла input.txt и
выводом в output.txt, просмотр реестра найденных чисел, резервное
копирование реестра, восстановление реестра из копии и выход. Результат
каждого поиска сохраняется в реестре. Для реестра предусмотрены резервное
копирование и восстановление из последней копии.

### 6. Обзор программного средства

**Системный интерфейс.** Программа работает под управлением операционных
систем Windows, Linux или macOS и не требует прав администратора.
Обращений к системным службам нет: все данные хранятся в текстовых файлах
рядом с программой.

**Пользовательский интерфейс.** Текстовый интерфейс в окне консоли:
программа печатает меню, пользователь вводит номер пункта и число N.
Все сообщения выводятся на русском языке.

**Аппаратный интерфейс.** Используются стандартные устройства ввода-вывода:
клавиатура и монитор. Специальные требования к оборудованию не
предъявляются.

**Программный интерфейс.** Внешние программы и библиотеки не вызываются.
Используется только стандартная библиотека Python 3 (модули os, shutil,
datetime).

**Коммуникационный интерфейс.** Не используется: программа полностью
работает на локальном компьютере, сетевое подключение не требуется.

**Ограничения по памяти.** Для работы программы достаточно до 100 МБ
оперативной памяти. Реестр и резервные копии — небольшие текстовые файлы,
занимают на диске несколько килобайт.

**Операции.** Запуск программы выполняется командой `python main.py`,
проверка тестов — командой `python tests.py`. Все остальные операции
выбираются в меню программы.

**Требования к адаптации рабочих мест.** Не предъявляются: программа
хранит все файлы в своей папке и работает из любого каталога, в который
она скопирована.

**Функциональное описание.** Программа должна:
– находить все числа Армстронга в диапазоне от 1 до заданного значения N
  включительно;
– принимать границу N с консоли или из файла input.txt;
– выводить результаты на экран или в файл output.txt по одному числу
  в строке;
– при некорректном вводе (текст вместо числа, число меньше 1,
  отсутствующий файл) выводить сообщение об ошибке и не завершаться
  аварийно;
– вести реестр найденных чисел registry.txt: дата и время, диапазон,
  найденные числа;
– создавать резервные копии реестра в папке backup и восстанавливать
  реестр из последней копии.

**Характеристики пользователя.** Пользователь должен уметь запускать
программы из командной строки. Специальные знания в программировании не
требуются: все действия выполняются через меню.

**Ограничения.** Срок разработки — период учебной практики с 05.10.2026
по 17.10.2026. Язык разработки — Python 3, сторонние библиотеки не
используются. Проект выполняется одним разработчиком.

**Допущения и зависимости.** Поиск выполняется простым перебором всех
чисел от 1 до N, поэтому при очень больших значениях N поиск может идти
долго. Работа программы зависит от наличия установленного Python 3.

**Распределение требований.** Требования к поиску, вводу-выводу, реестру
и проверке ввода реализуются в файле main.py, требования к резервному
копированию — в файле backup.py, проверка выполнения требований — в
файле tests.py. Документация программы оформлена в файлах README.md,
ТЗ.md и Регламент_ТО.md.
